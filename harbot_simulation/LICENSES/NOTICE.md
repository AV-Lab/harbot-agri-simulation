`harbot_simulation` combines the adapted RB-KAIROS Gazebo package with
HARBOT-specific simulation bringup.

- The Gazebo package, worlds, models, and RViz configuration originated from
  the Robotnik RB-KAIROS simulation and retain the BSD license declared by
  that package. The available Robotnik license text is included as
  `Robotnik-BSD-3-Clause.txt`.
- HARBOT-specific bringup and workflow additions retain the repository's MIT
  license, included as `HARBOT-MIT.txt`.

This consolidation changes ROS package organization; it does not relicense
third-party source code or assets.
